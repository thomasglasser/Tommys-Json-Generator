---
title: Using the Generators and Making an Addon
---

Welcome to the JSON Generator site! This guide will walk you through the process of using the generators, making an addon, and putting it in the game.

## Using the Generators

On this site, you can find a variety of generators for both vanilla and mod content.
To begin, click on the generator you want to use.
This will open the generator page with fields for you to fill in.
You can fill these in from scratch or use a preset by choosing one from the dropdown in the top right.
Fields can autocomplete any vanilla or mod content, or you can type in your own.
Once you're done, you can either download the file or save it to the active project.

## Saving Individual Files

If you want to share, download, or copy a single file, you can click on the respective button in the bottom right.
You can then place the file in your data or resource pack.
Refer to the [Minecraft Wiki](https://minecraft.wiki) for more information on creating [data](https://minecraft.wiki/w/Tutorial:Creating_a_data_pack) and [resource](https://minecraft.wiki/w/Tutorial:Creating_a_resource_pack) packs.

## Saving to the Active Project

The site tracks an active project in your browser.
This can be shown or hidden by clicking the book icon in the bottom left.
To save a file to the active project, click CTRL+S or click the save button in the top right dropdown and give the file an ID.
If you haven't created a project yet, the file will be saved in a `Drafts` folder.

## Saving the Entire Project

To save the active project, click the dropdown in the top right of the project menu and click `Download Data Pack`.
This will download a zip file containing all the files in the project that can then be loaded in-game.

## Loading the Project in-game

See the [Minecraft Wiki](https://minecraft.wiki) for information on loading [data](https://minecraft.wiki/w/Tutorial:Installing_a_data_pack) and [resource](https://minecraft.wiki/w/Tutorial:Loading_a_resource_pack) packs.
